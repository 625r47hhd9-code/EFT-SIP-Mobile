EFT SIP Mobile M7.3

Основное:
- нижняя панель имеет 3 состояния: peek / compact / full;
- после создания объекта панель автоматически открывается в compact;
- при обычном выборе она остаётся маленькой, свайп вверх раскрывает настройки;
- при снятом выборе полный свайп показывает контрольные параметры дома;
- тап инструментом «Выбор» по пустому полю снимает выбор;
- блок стрелок лишён белой подложки и перетаскивается за зелёную центральную кнопку;
- размер ставится двумя точками с привязкой к сетке/узлам;
- подписи комнат, площадей, размеров и техподписи увеличиваются вместе с zoom;
- сетка 1×1 м усилена и остаётся фоновым слоем;
- стены и перегородки показаны светлыми полосами с штриховой осью, чтобы сваи/обвязка не терялись;
- сохранены проверенные расчёты общих перегородок без задвоения.
