# ЭФТ — калькулятор СИП-дома

Веб-приложение для планировки дома, расчёта свай, СИП-панелей, кровли, террас, проёмов, крепежа, работ и итоговой сметы.

## Быстрый запуск

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173/`). Не открывайте `index.html` двойным щелчком: рабочее приложение должно запускаться через локальный сервер или GitHub Pages.

Проверка перед публикацией:

```powershell
npm test
npm run build
npm run preview
```

## Редактор плана

В разделе «План дома» можно начать с готового эскиза или выбрать «Новый чистый план». Основные правила работы:

- «Комната» рисует прямоугольник протягиванием, «Многоугольная» — помещение неправильной формы по узлам;
- режим «Выбор» двигает комнаты, стены, проёмы, террасы, сваи и свайные ряды; зелёные точки меняют форму или длину;
- комнаты и узлы прилипают к соседним стенам, а зазоры, пересечения и выход за контур отмечаются красным;
- «Разрыв стены» удаляет выбранный участок стены и вычитает его из расчёта;
- окна и двери автоматически устанавливаются на ближайшую стену, после чего справа задаются размеры, тип и открывание;
- для террасы и крыльца справа настраиваются ступени, свайное поле, обвязка и кровля;
- сваи, обвязку и размеры можно независимо скрыть; число свай в ряду меняется в правой панели;
- любое изменение возвращается стрелкой «Отменить», а текущий вариант можно сохранить в список эскизов.

## Сохранение проекта и защита от потери данных

React-приложение автоматически сохраняет текущее состояние в браузере после каждого изменения. Кнопка с дискетой одновременно создаёт резервную копию в браузере и скачивает переносимый файл `.eft.json`. В нём находятся:

- карточка проекта и параметры;
- редактируемый план, комнаты, стены, проёмы, пристройки, сваи и обвязка;
- параметры всех калькуляторов и состав расчёта;
- действующий прайс материалов и работ;
- выбранный режим цен.

Кнопка со стрелкой вверх открывает `.eft.json`. Кнопка с листом создаёт новый проект, предварительно сохранив текущий в резервные копии. Доступны 60 шагов отмены и повтора; браузер хранит до 10 контрольных копий.

Автосохранение помогает после аварийного закрытия, но не заменяет файл проекта. Для надёжной работы скачивайте `.eft.json` после важного этапа и храните его вместе с документами заказа или в облаке.

## Прайс-лист

Раздел «Прайс-лист» содержит две независимые редактируемые таблицы:

- материалы, оборудование и комплектующие;
- строительные и монтажные работы.

Изменение цены обновляет калькуляторы и смету. Прайс сохраняется тремя способами:

1. Внутри каждого файла проекта `.eft.json` — проект откроется с теми ценами, по которым считался.
2. В браузере — текущий рабочий каталог восстанавливается при следующем запуске.
3. Отдельным файлом `Прайс-лист_ЭФТ.json` — для переноса общей базы цен между компьютерами.

Кнопки раздела:

- **Скачать** — переносимый редактируемый каталог JSON;
- **Загрузить** — заменить материалы и работы из ранее сохранённого каталога;
- **Исходный** — восстановить встроенные 172 позиции материалов и 99 позиций работ;
- **Скачать Excel** в смете — получить три листа: смета, материалы и работы.

Перед массовым изменением цен рекомендуется сохранить отдельную копию прайса. При открытии проекта его прайс заменяет текущий каталог, чтобы сохранить воспроизводимость сметы.

## Связи и формулы

Кнопка с ползунками **⚙ «Настройка расчётов»** в правом верхнем углу открывает сквозную схему расчёта:

`план → геометрические показатели → калькуляторы → номенклатура → прайс → смета`.

Экран показывает источник каждой основной величины, формулу, текущий результат, получателя и состояние связи. Там же проверяется, нашла ли каждая расчётная строка позицию и цену в прайсе.

По умолчанию с планом автоматически связаны длина конька, инженерные трассы, отделочные площади и объём доставки. Связь можно отключить и перейти на ручное значение. Редактируемые коэффициенты СИП, крепежа, свай, кровли, террасы, инженерии и доставки сохраняются внутри файла проекта. Кнопка «Исходные коэффициенты» возвращает заводские значения.

## GitHub Pages

1. Создайте на GitHub приватный или публичный пустой репозиторий.
2. Добавьте его как `origin` и отправьте ветку `main`.
3. В настройках репозитория откройте **Settings → Pages**.
4. В качестве Source выберите **GitHub Actions**.

Workflow автоматически запускает тесты, собирает приложение и публикует папку `dist`.

## Мобильная версия

Приложение является адаптивным PWA: его можно установить из браузера на Android или компьютер. React-код и независимое расчётное ядро готовы для последующей упаковки через Capacitor в APK/iOS без переписывания калькуляторов.
