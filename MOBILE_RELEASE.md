# EFT SIP Mobile M7.5.3 Safari

- выбор комнаты на iPhone Safari выполняется сразу на pointer-down;
- повторное касание уже выбранной комнаты начинает её перемещение;
- у комнаты есть отдельная прозрачная сенсорная область;
- объединённые декоративные стены и наружный контур больше не перехватывают касания комнаты;
- добавлена очистка состояний при lostpointercapture/pointercancel Safari;
- запрещены системное выделение, callout и overscroll внутри редактора;
- сохранена геометрия M7.5.2, включая светлые стены, внутренний snap-контур и 84 расчётных теста.
