# EFT SIP Mobile — параметрическая визуализация

Эта ветка/пакет создана как самостоятельная мобильная React-версия EFT SIP Calculator.

## Что изменено
- iPhone-first оболочка с safe-area для Dynamic Island / чёлки и Home Indicator.
- Основная навигация: Дом, Конструкция, Материалы, Раскрой, Смета.
- Инженерия скрыта из мобильной навигации, но совместимость старых проектов сохранена.
- В разделе «Дом» добавлен экран «3D» с параметрической визуализацией.
- Режимы визуализации: 3D, План, Каркас, СИП, Кровля.
- Визуализация читает реальные размеры дома, высоту стен, параметры кровли, помещения, наружные проёмы, террасы и результаты СИП-расчёта.
- Существующий расчётный движок, прайс, сохранение, экспорт и тесты оставлены базой проекта.
