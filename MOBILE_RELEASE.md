# EFT SIP Mobile M7.7.2

## Главная переработка: редактор кровли сверху

- Вкладка «Кровля» больше не показывает объёмную модель. Объём кровли остаётся только в 3D-виде.
- Кровля сделана по принципу редактора плана: большой схематичный вид сверху и отдельные слои.
- Слои: «Несущая», «Контробрешётка», «Обрешётка», «Кровля».
- Несущая схема автоматически показывает стропила либо фермы в зависимости от выбранной стропильной системы.
- Поддержаны три системы из основного калькулятора: висячая, наслонная и стропильные фермы.
- Отображаются контур дома, габарит кровли со свесами, конёк, расположение стропил/ферм, контробрешётка, шаг обрешётки и направление профлиста С-21.
- Настройки конструкции находятся прямо под схемой и используют те же поля проекта, что основной калькулятор.
- Автоматический и ручной режимы расчёта сохранены.
- Добавлены сводки по стропилам, обрешётке, мауэрлату, коньковому прогону и площади скатов.
- 3D-вкладка и обзорный план сохранены без изменения их основной логики.

Версия: M7.7.2
