# EFT SIP Mobile v0.4

- Параметры перестроены под iPhone: главное сверху, редкие настройки раскрываются.
- Инженерия удалена из мобильного состава расчёта.
- План получил компактную панель частых действий; служебные команды спрятаны в «Ещё».
- Три главных размера плана остаются видимыми в одной строке.
- Визуализация использует ту же модель проекта и получила кнопку «Снять крышу».
- Расчётное ядро не изменялось.
- Версия интерфейса: M5.


## M5 · полноэкранный редактор плана
- Поле плана занимает весь экран iPhone.
- Компактные плавающие панели сверху и слева.
- Pinch-to-zoom двумя пальцами и кнопки масштаба.
- Блеклая сетка с быстрым выключением.
- Увеличенные технические подписи.
- Контекстная нижняя плашка для выбранного объекта.
- Быстрое изменение размеров шагом 10 см.
- На экране размеры округляются до двух знаков после запятой.
- Меню «Вид» для перехода в 3D / Каркас / СИП / Кровлю.
- Расчётное ядро не изменено.
