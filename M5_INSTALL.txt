1. Распакуйте архив.
2. Скопируйте ВСЁ содержимое папки в локальную папку репозитория EFT-SIP-Mobile с заменой файлов.
3. GitHub Desktop: Summary = "EFT SIP Mobile M5".
4. Commit to main.
5. Push origin.
6. Дождитесь зелёной GitHub Actions / Pages и обновите сайт.
